Contas

Múltiplas contas exigem macOS 14 ou superior.

Notificações

O detector adicional só usa mensagens novas identificáveis. Conversas silenciadas, histórico e estados desconhecidos não geram avisos adicionais.

Comportamento

Aparência

Ícone do aplicativo Padrão

Imagem PNG quadrada, de 32 a 1024 px e até 5 MB. Vale para o aplicativo todo; a bandeja não muda. No Linux com Wayland, o ícone da janela vem do arquivo .desktop e não muda.

Pasta de downloads Pasta Downloads do sistema

Rede

Proxy com usuário e senha não é suportado: os navegadores embutidos não aceitam credenciais por esse caminho. A alteração vale após reiniciar o whatRust.

Reinicie o whatRust para aplicar o proxy.

Segurança

O bloqueio protege o acesso às janelas do whatRust. Ele não criptografa os dados no disco.

Novidades

Versões 0.6.10 e anteriores não atualizam sozinhas: instale esta versão manualmente uma vez. Cada arquivo baixado é conferido com a soma de verificação (SHA-256) publicada na versão antes de ser instalado.
