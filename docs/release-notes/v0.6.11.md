## whatRust v0.6.11

**whatRust now updates itself**, drag-and-drop works again on Linux, and there's a privacy blur, a proxy setting, zoom shortcuts, your own download folder and app icon, an optional single window for all accounts on Linux and macOS, and the unread count on the Linux dock.

### Automatic updates

whatRust can now update itself. A minute after start, and every 6 hours after that, it asks GitHub (`api.github.com`) for the newest release. It sends nothing but a `whatRust/<version>` User-Agent. If a newer version exists you get a notification, an **Update to X.Y.Z** item in the tray menu, and the release notes under **Settings → Updates**. Every download is checked against the SHA-256 published with the release (`SHA256SUMS`) before anything is replaced or started. If the check fails, nothing is changed.

- **AppImage and macOS:** replaced in place in the background; the new version starts the next time you open the app.
- **Windows:** the installer is downloaded and checked in the background, then runs when you click **Restart and install**.
- **.deb:** installed when you click **Download and install**, after the system asks for your administrator password.
- **Flatpak:** the verified bundle is saved in Downloads and opened in your software center.

Updates go through the proxy from Settings → Network. To turn this off, untick **Check for updates automatically** in **Settings → Updates**. **0.6.10 and older do not have the updater, so install this version by hand once** (commands below); from here on, updates arrive on their own.

### Fixed

- **Linux: drag-and-drop works again.** In 0.6.9 and 0.6.10, files dragged onto whatRust from a file manager never reached the chat in the `.deb`, AppImage and Flatpak builds. whatRust was listening for the drop on the window, but since 0.6.9 the webview receives it. A 30 MB file now streams in about a second, as before.
- **Thin scrollbars.** The chat list and the conversation no longer show a thick white scrollbar on the dark theme. On macOS whatRust uses overlay scrollbars for itself only, without changing the system-wide setting. Thanks to @t43riz (#62).
- **Settings icon.** The settings button now uses a proper gear, consistent with WhatsApp's own icons. Thanks to @viktorstarscollector (#61).

### New

- **Privacy blur.** Blur message text, chat previews, media, the gallery, the text box, profile pictures or names. Hovering reveals a single item, and the app can blur itself when idle or hidden. Press `Ctrl+Shift+P` (`⌘+Shift+P` on a Mac) in a WhatsApp window to choose what to blur. An optional global shortcut toggles the blur in every account (Settings → Shortcuts). It is off until you turn it on. Thanks to @vrieza (#57) and @tazkirap for the idea (#50).
- **Hide the Dock icon (macOS).** Keeps the normal window and uses the menu bar icon to come back (#57).
- **Zoom shortcuts.** `Ctrl` + `+` / `-` / `0` (`⌘` on a Mac), `Ctrl` + mouse wheel, and pinch zoom WhatsApp in steps. The level applies to every account and is remembered, and Settings → Display size follows it (#40).
- **Download folder.** Settings → Appearance → Download folder lets you choose a folder (*Choose folder…*) or go back to Downloads. In the Flatpak the folder is picked through the system portal, so it needs no extra permission. On Windows the Save As dialog opens in that folder (#40).
- **Your own app icon.** Settings → Appearance → App icon accepts a square PNG (32–1024 px). It replaces the Dock icon on macOS and the window and taskbar icon on Windows, and the unread badge still shows on top. On Linux it changes the window icon on X11; Wayland docks use the installed icon. Thanks to @simonespongano (#54).
- **Proxy.** Settings → Network routes every account through a SOCKS5 or HTTP proxy (host and port) after a restart; a *Restart now* button is provided. Proxies that need a username and password aren't supported by the system webviews. On macOS this needs macOS 14 or later (#52, thanks @VixenSugo).
- **All accounts in one window (Linux and macOS).** Settings → Accounts → *Show all accounts in one window* puts every account in a single window with a switcher at the top. Hidden accounts stay connected for notifications. It is off by default and applies after a restart. Windows already works this way, thanks to @matheuscardosoj's work in 0.6.9. On macOS it needs macOS 14 or later. This is new, so please report anything odd (#41, thanks @abdul-mustapha).
- **Unread count on the Linux dock.** The number now also appears on the launcher icon in KDE Plasma, Ubuntu Dock / Dash to Dock, Plank and Latte, like the macOS Dock badge and Windows taskbar overlay added in 0.6.10. Stock GNOME shows no app-icon badges without one of those docks. The Flatpak asks for one extra D-Bus name (`com.canonical.Unity`) for this.

### Install or update

```bash
# Linux (Flatpak)
curl -fsSL https://raw.githubusercontent.com/karem505/whatRust/master/install-flatpak.sh | sh
# Linux (AppImage) and macOS
curl -fsSL https://raw.githubusercontent.com/karem505/whatRust/master/install.sh | sh
```

On Windows, run the `x64-setup.exe` or `.msi` below.
