## whatRust v0.6.8

An option to hide the menu bar icon on macOS, and two fixes for Windows.

### macOS

- **New:** Settings → Behavior → **Show menu bar icon**. Turn it off to keep whatRust out of the menu bar; click its Dock icon to bring the window back. It's on by default. Thanks to @Dumboiroy for the suggestion in #44.

### Windows

- **Fixed:** the Display size list in Settings → Appearance no longer opens as a blank white box in dark mode. Thanks to @viktorstarscollector for the report in #40.
- **Fixed:** notifications now show the whatRust logo in their header instead of a generic window icon (also #40). Windows may keep showing the old icon until you sign out and back in once.

### Linux

- The FAQ now explains why voice and video calls don't work on Linux: the WebKitGTK inside the AppImage is built without WebRTC (#39).

### Install or update

```bash
# Linux (AppImage) and macOS
curl -fsSL https://raw.githubusercontent.com/karem505/whatRust/master/install.sh | sh
# Linux (Flatpak)
curl -fsSL https://raw.githubusercontent.com/karem505/whatRust/master/install-flatpak.sh | sh
```

On Windows, run the `x64-setup.exe` or `.msi` below.
