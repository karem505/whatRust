## whatRust v0.7.0

**Do not disturb, a notification-sound switch, sleeping accounts, settings backup, Ctrl+1…9 account switching, paste for images and files on Linux, a faster start with several accounts, and fixes for downloads, the Windows taskbar icon, call pop-outs and idle audio on Linux.**

This is a feature release, so the version moves to 0.7. Thanks to everyone who sent code, reports and screenshots this round.

### New

- **Do not disturb.** Settings → Notifications → **Do not disturb**: no whatRust notifications between a start and an end time (local time, it may cross midnight). Messages still arrive. Off by default. (#113, thanks @Ahmed-Bilal-Qazi)
- **Notification sound switch.** Settings → Notifications → **Notification sound** silences WhatsApp's own message tones and the sound of Windows toasts. Calls still ring and voice notes still play. On by default, so nothing changes until you turn it off. (#108, thanks @giovannicruz97)
- **Sleep unused accounts.** With all accounts in one window, Settings → Appearance → **Sleep unused accounts** unloads a background account that has not been opened for 1, 4, 8 or 24 hours, which frees its memory. It reloads when you switch to it; while asleep it gets no notifications. Off by default. (#111, thanks @Ahmed-Bilal-Qazi)
- **Settings backup.** Settings → Appearance → **Save backup… / Restore backup…** writes your preferences and account list (names, order, startup account) to a JSON file. Logins, chats and the lock password are never included; accounts that are new on this computer ask for the QR code after a restart. (#115, thanks @Ahmed-Bilal-Qazi)
- **Ctrl+1…9 (Cmd on macOS) opens the Nth account**, like browser tabs. Only with more than one account; otherwise the keys reach WhatsApp as before. (#110, thanks @Ahmed-Bilal-Qazi)
- **See which account needs you.** With all accounts in one window, the title lists the other accounts that have unread chats (`whatRust — Personal · Work (3)`), and on Windows 11 the window border takes the shown account's colour when you have more than one account. (#114, thanks @Ahmed-Bilal-Qazi)
- **Linux: paste images and files.** `Ctrl+V` now attaches a screenshot, a copied image, or files copied in your file manager. WebKitGTK hid them from WhatsApp before. (#105 for #104, thanks @mhasant19)
- **WhatsApp's header can stay untouched.** On Windows and in the one-window mode, turn off **Settings → Appearance → whatRust controls in WhatsApp's header** to leave the page as WhatsApp draws it. (#95, thanks @schoolerani-spec)
- **Linux `.rpm` packages** (x86_64 and aarch64) for Fedora, openSUSE and similar. whatRust tells you about new versions; install the next `.rpm` with your package manager.

### Faster

- **The account you are waiting for loads first.** With several accounts, only the startup account is built at launch; the others follow once its chat list is on screen (or after 45 s, or when you switch to one). One two-account Windows machine went from about 37 s to about 10 s to the first chat list. (#109, thanks @Ahmed-Bilal-Qazi)
- **Dropping or pasting a file attaches it at once**, without the one-second pause after the attach menu opened. (#105 for #106, thanks @mhasant19)

### Fixes

- **Linux: idle sounds no longer pile up.** WebKitGTK kept one audio stream open for every WhatsApp sound that was played and then paused, so the volume mixer filled with idle whatRust entries. A sound paused for 20 seconds now gives its stream back and gets it again the next time it plays. Voice notes and calls are not touched. This does not remove the whatRust media player that GNOME keeps showing (#120); that needs a separate fix. If CPU use still creeps up over a long session on 0.7.0 (#121), please add the details asked for in that issue.
- **Downloads no longer get a doubled extension** such as `photo.jpg.jpeg` or `song.mp3.mpeg`. (#123, thanks @panjidwiprasetya-ux)
- **Windows: the taskbar shows the whatRust icon** instead of a blank window. Windows was given only the small icon. (#117, thanks @LucasVelloso21 for the exact diagnosis)
- **Windows: the save dialog opens in your download folder** (not System32) and its title follows whatRust's language. (#90, thanks @mhanxhan)
- **Linux: images saved from a chat get a real name** (`whatsapp-<date>-<time>.jpg`) inside your download folder, instead of ` (1)` next to it. (#92, thanks @Nico2433)
- **The account picker fills the window** when whatRust starts maximized. (#91, thanks @brianfauzanlukman)
- **Windows: WhatsApp's "Open in bigger view" call button opens the call window** and the call no longer hangs. The pop-out can only show WhatsApp and closes with its account. (#96, thanks @schoolerani-spec)
- **Windows: no flicker of the top bar** when the profile drawer opens or closes (#95), **one title bar while WhatsApp loads** (#112), and the in-page controls no longer drop out on displays with a fractional scale (#116). (thanks @schoolerani-spec and @Ahmed-Bilal-Qazi)

### Install or update

```bash
# Linux (Flatpak)
curl -fsSL https://raw.githubusercontent.com/karem505/whatRust/master/install-flatpak.sh | sh
# Linux (AppImage) and macOS
curl -fsSL https://raw.githubusercontent.com/karem505/whatRust/master/install.sh | sh
```

On Windows, run `x64-setup.exe` (or the `.msi`), or `arm64-setup.exe` on ARM64. Fedora/openSUSE: install the `.rpm` for your architecture. If you are on 0.6.11 or later, whatRust installs this update on its own (AppImage, macOS, Windows) or offers it in **Settings → About whatRust** (`.deb`, Flatpak).

**macOS `.dmg`: "whatRust is damaged and can't be opened"?** The app isn't damaged. It is not signed with an Apple Developer ID, so macOS blocks it after a browser download. Drag it into Applications, run `xattr -dr com.apple.quarantine /Applications/whatRust.app` once in Terminal, and open it again. The `install.sh` line above does this for you.
