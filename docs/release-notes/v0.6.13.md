## whatRust v0.6.13

**Linux: smooth scrolling on laptops with two graphics cards.**

On laptops where Intel or AMD graphics drive the screen and an NVIDIA card is there for heavier work (common with NVIDIA's "Optimus"), whatRust turned off WebKit's fast rendering path just because the NVIDIA driver was installed. Scrolling chats and typing felt sluggish as a result. That workaround is only needed when NVIDIA drives the display, so whatRust now applies it only then. On an Intel UHD + Quadro P520 laptop scrolling went from sluggish to smooth (#78).

If you had set `WEBKIT_DISABLE_DMABUF_RENDERER` yourself, for example with `flatpak override`, whatRust still respects it.

Also since 0.6.12: the Flatpak installer now fixes a lost Flatpak document-portal mount, which stopped every Flatpak app from opening with `bwrap: Can't find source path …/doc/by-app/…`. The README explains the macOS "whatRust is damaged" message on a browser-downloaded `.dmg`, and the one command that clears it.

If you are on 0.6.11 or 0.6.12, whatRust installs this update on its own (AppImage, macOS, Windows) or offers it in **Settings → Updates** (.deb, Flatpak).

### Install or update

```bash
# Linux (Flatpak)
curl -fsSL https://raw.githubusercontent.com/karem505/whatRust/master/install-flatpak.sh | sh
# Linux (AppImage) and macOS
curl -fsSL https://raw.githubusercontent.com/karem505/whatRust/master/install.sh | sh
```

On Windows, run the `x64-setup.exe` or `.msi` below. 0.6.10 and older don't have the updater, so install this version by hand once.

**macOS `.dmg`: "whatRust is damaged and can't be opened"?** The app isn't damaged. It is not signed with an Apple Developer ID, so macOS blocks it after a browser download. Drag it into Applications, run `xattr -dr com.apple.quarantine /Applications/whatRust.app` once in Terminal, and open it again. The `install.sh` line above does this for you.
