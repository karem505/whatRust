## whatRust v0.6.7

Profile pictures on notifications, and fixes for possible freezes on Windows.

### Profile pictures on notifications

- **New:** message and call notifications now show the sender's profile picture: round on Windows, as the notification icon on Linux. Thanks to @mhanxhan for the suggestion in #3.
- whatRust uses the picture WhatsApp attaches to its own notification, scaled down to a small image. It's kept in whatRust's cache folder only so the notification can show it, and removed after a day. When there's no picture, or it can't be loaded within a moment, the notification appears without one, as before.
- macOS notifications always show the app icon, so nothing changes there.
- The diagnostic log only records whether a picture was attached, never the picture or where it came from.

### Windows

- **Fixed:** possible freezes when adding or opening an account, opening Settings, or using "Lock now". Creating a new window from inside WebView2's message handler can deadlock, so these now run in the background. Thanks to @matheuscardosoj for finding this in #26.
- **Fixed:** saving Settings with "Launch at system startup" turned off no longer shows an error when it was already off.
- Two account changes made at the same moment can no longer overwrite each other, and an account whose window fails to open is removed again instead of being left behind.

### Install or update

```bash
# Linux (AppImage) and macOS
curl -fsSL https://raw.githubusercontent.com/karem505/whatRust/master/install.sh | sh
# Linux (Flatpak)
curl -fsSL https://raw.githubusercontent.com/karem505/whatRust/master/install-flatpak.sh | sh
```

On Windows, run the `x64-setup.exe` or `.msi` below.
