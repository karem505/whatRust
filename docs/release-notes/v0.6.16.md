## whatRust v0.6.16

**Builds for ARM and Intel on every system, a working in-app update for Flatpak, and fixes for old GPUs, openSUSE/Fedora AppImages, KDE title bars and typing after Alt+Tab.**

### New downloads

- **Linux ARM64:** AppImage and `.deb` (the Flatpak already had ARM64).
- **macOS Intel:** a `.dmg` for Intel Macs, next to the Apple Silicon one.
- **Windows ARM64:** an ARM64 installer (`arm64-setup.exe`). There is no ARM64 `.msi`: the MSI tool can't build one.

The install scripts pick the right file for your machine.

### Fixes

- **KDE/Wayland: title-bar buttons work with one click** after the window comes back from the tray. whatRust now uses Tauri 2.12, which carries the fix. (#88, thanks @Nico2433)
- **Old graphics cards: no more blank window after login.** On Intel graphics older than Sandy Bridge (OpenGL 2.1) whatRust now draws without the GPU on its own. If the window stays blank on another GPU, try **Settings → Appearance → Rendering → Compatible**. (#87, thanks @yudhapriaw)
- **Windows: typing works right after Alt+Tab.** Keyboard focus goes back to the message box without a click. (#85, thanks @brianfauzanlukman)
- **AppImage on openSUSE, Fedora and similar: "Unacceptable TLS certificate" is fixed.** The AppImage now uses your system's TLS library, which knows where your distro keeps its certificates. (#84, thanks @ciro314)
- **Flatpak: Settings → About whatRust → Download and install now installs the update** and restarts whatRust. Before, it only opened the file in the software centre, and some software centres never installed it. This applies from 0.6.16 on: the 0.6.15 button still opens the file, so if that doesn't install it, use the Flatpak command below.

### Changes

- **"Get WhatsApp for Windows/Mac" prompts are hidden**, including the banner under the chat list. To see them again, turn off **Settings → Appearance → Hide WhatsApp app promotions** and restart whatRust. (#83, thanks @brian-wee and @brianfauzanlukman)
- **Each account window can show its own picture.** On Linux and Windows, an account with a profile photo uses it as its window icon, so the taskbar and Alt+Tab show which account is which. macOS has one Dock icon per app, so it stays the app icon there. (#54)
- **Settings polish:** account rows have room around the photo and the menu button, the privacy blur panel uses the Settings font, and **About whatRust** has an info icon and shows the version. (#82, thanks @brianfauzanlukman)
- **Voice and video calls work on Windows** now that WhatsApp Web offers them there; the README says so. Linux still can't place calls. (#86, thanks @brianfauzanlukman)

**Flatpak permission:** to install updates, the Flatpak may now ask the system's Flatpak to run `flatpak install` (`--talk-name=org.freedesktop.Flatpak`). whatRust uses this only for updates.

If you are on 0.6.11 or later, whatRust installs this update on its own (AppImage, macOS, Windows) or offers it in **Settings → About whatRust** (.deb, Flatpak).

### Install or update

```bash
# Linux (Flatpak)
curl -fsSL https://raw.githubusercontent.com/karem505/whatRust/master/install-flatpak.sh | sh
# Linux (AppImage) and macOS
curl -fsSL https://raw.githubusercontent.com/karem505/whatRust/master/install.sh | sh
```

On Windows, run `x64-setup.exe` (or the `.msi`), or `arm64-setup.exe` on ARM64. 0.6.10 and older don't have the updater, so install this version by hand once.

**macOS `.dmg`: "whatRust is damaged and can't be opened"?** The app isn't damaged. It is not signed with an Apple Developer ID, so macOS blocks it after a browser download. Drag it into Applications, run `xattr -dr com.apple.quarantine /Applications/whatRust.app` once in Terminal, and open it again. The `install.sh` line above does this for you.
