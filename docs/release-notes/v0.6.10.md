## whatRust v0.6.10

The unread count on the app icon, smoother scrolling in the Flatpak, and a fix for the macOS installer.

### Unread count on the app icon

- **macOS:** the Dock icon now shows a red badge with the number of unread chats, like other messaging apps. Thanks to @simonespongano for the suggestion (#54).
- **Windows:** the taskbar button now shows the unread count in a red circle, "99+" above 99. Thanks to @FrankLoq for the suggestion (#55).
- The tray and menu bar icons keep showing the count as before.

### Linux

- **Fixed:** scrolling and typing stuttered in the Flatpak, because it turned off WebKitGTK's GPU buffer sharing for everyone. whatRust now turns it off only with NVIDIA's proprietary driver, where it has caused blank windows. Thanks to @kikiexe for tracking this down (#51). To override it either way, set `WEBKIT_DISABLE_DMABUF_RENDERER` yourself, e.g. `flatpak override --user --env=WEBKIT_DISABLE_DMABUF_RENDERER=0 io.github.karem505.whatRust`.

### macOS

- **Fixed:** the one-line installer failed with "No .app inside the dmg" when a whatRust disk image was already open, and left its own copy mounted. It now mounts the image at a private location and always cleans up. Thanks to @rbansal42 for the report and fix (#58, #59).

### Install or update

```bash
# Linux (AppImage) and macOS
curl -fsSL https://raw.githubusercontent.com/karem505/whatRust/master/install.sh | sh
# Linux (Flatpak)
curl -fsSL https://raw.githubusercontent.com/karem505/whatRust/master/install-flatpak.sh | sh
```

On Windows, run the `x64-setup.exe` or `.msi` below.
