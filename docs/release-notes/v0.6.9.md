## whatRust v0.6.9

The first release since v0.6.7. It adds a menu-bar-only mode on macOS, an interface language setting (English or Português), a sturdier app lock and many Windows fixes.

### Everywhere

- **New:** Settings → Appearance → **Language**: English or Português (Brasil). A new install follows your system language; if you update from an earlier version, whatRust stays in English. Thanks to @matheuscardosoj (#49).
- **Safer app lock:** a growing delay after three wrong passwords, a 6-character minimum, and resetting the lock now asks for confirmation. If the lock file is ever damaged, the lock stays on instead of turning itself off.
- **Settings and accounts are saved safely:** each file is written to a temporary copy first and a backup is kept, so a crash or full disk can no longer leave you with an empty account list.
- **Downloads:** only common file types open directly; anything else is shown in its folder instead.
- Microphone and camera permissions are granted to `web.whatsapp.com` only.

### macOS

- **New:** a **menu-bar-only mode**. whatRust lives in the menu bar with no Dock icon; every account stays connected and opens as a panel from the menu bar icon. Thanks to @janbridley. Requires macOS 14 or later.
- **New:** Settings → Behavior → **Show menu bar icon**. Turn it off to keep whatRust out of the menu bar; click the Dock icon to bring the window back. Thanks to @Dumboiroy for the suggestion (#44).
- **Fixed:** dragging files into a chat works again.

### Windows

- **Fixed:** notifications arrive reliably, also when the window is minimized, and show the whatRust logo (#40).
- **Fixed:** freezes when resizing the window or signing in to a new account, and accounts that did not activate on startup.
- **Fixed:** the Display size list in Settings → Appearance no longer opens blank in dark mode (#40).
- The installer is available in English and Português and verifies its download.

### Linux

- The FAQ explains why voice and video calls don't work in the AppImage: its WebKitGTK is built without WebRTC (#39).

### Install or update

```bash
# Linux (AppImage) and macOS
curl -fsSL https://raw.githubusercontent.com/karem505/whatRust/master/install.sh | sh
# Linux (Flatpak)
curl -fsSL https://raw.githubusercontent.com/karem505/whatRust/master/install-flatpak.sh | sh
```

On Windows, run the `x64-setup.exe` or `.msi` below.
