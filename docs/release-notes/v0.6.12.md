## whatRust v0.6.12

A fix release for 0.6.11: arrow keys on macOS, profile pictures on Windows notifications, and the download popup. On Linux, whatRust also fits in with tiling window managers like Hyprland.

If you are on 0.6.11, whatRust installs this update on its own (AppImage, macOS, Windows) or offers it in **Settings → Updates** (.deb, Flatpak). This is the first release delivered by the new in-app updater.

### Fixed

- **macOS: arrow keys no longer type symbols into the chat.** Since 0.6.9, pressing an arrow key (or Home/End) when the cursor had nowhere to go added an unreadable character to the message box instead of doing nothing. The window behind WhatsApp was turning the unused key into text. It no longer does, and typing, shortcuts and input methods are unaffected. Thanks to @AwesomeGB for the report and the video (#73).
- **Windows: notifications show the sender's picture again.** In 0.6.11, message notifications on Windows lost the profile picture added in 0.6.7. The picture is now attached again: the notification waits at most 1.6 seconds for it, then shows anyway. Thanks to @mhanxhan and @viktorstarscollector (#72).
- **Download popup.** After a download, the "Show in folder" popup appeared as loose text with no background. A styling rule from 0.6.11 was cut short and hid the popup's style. Thanks to @viktorstarscollector (#71).
- **Settings.** A little space between the menu items, so the selected and hovered items no longer merge. The Appearance icon is now a palette (#71).

### New

- **Linux: no title bar on tiling window managers.** On Hyprland (including Omarchy), Sway, niri, i3, river and similar, whatRust no longer shows a GTK title bar with minimise, maximise and close buttons that do nothing there. GNOME, KDE and other desktops keep it. **Settings → Appearance → Title bar** shows the detected window manager and lets you choose *Automatic*, *Show* or *Hide*; the change applies at once.

### Install or update

```bash
# Linux (Flatpak)
curl -fsSL https://raw.githubusercontent.com/karem505/whatRust/master/install-flatpak.sh | sh
# Linux (AppImage) and macOS
curl -fsSL https://raw.githubusercontent.com/karem505/whatRust/master/install.sh | sh
```

On Windows, run the `x64-setup.exe` or `.msi` below.

**macOS `.dmg`: "whatRust is damaged and can't be opened"?** The app isn't damaged. It is not signed with an Apple Developer ID, so macOS blocks it after a browser download. Drag it into Applications, run `xattr -dr com.apple.quarantine /Applications/whatRust.app` once in Terminal, and open it again. The `install.sh` line above does this for you. 0.6.10 and older don't have the updater, so install this version by hand once.
