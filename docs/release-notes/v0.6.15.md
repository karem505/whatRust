## whatRust v0.6.15

**The privacy blur panel opens on Windows, the blur covers more, and Settings got a polish.**

### Privacy blur

- **Windows: the panel opens again.** Ctrl+Shift+P is also the browser's own "print" shortcut, and on Windows the web engine took it before whatRust could, so the panel never appeared. whatRust now takes the shortcut itself. The panel is also in the window menu: **whatRust → Privacy blur…** (#80)
- **A saved blur applies as soon as WhatsApp loads on Windows**, instead of only after you toggle it again.
- **More is blurred.** Contact and group names (also the sender names inside group chats), profile pictures everywhere (chat list, chat header, contact cards, voice notes, the media viewer), last-message previews, link, location and media previews, the media gallery and the text box.
- **Notifications follow the blur.** While the blur is on, a notification shows "WhatsApp — New message" without the sender's name, text or photo. You can turn this off in the panel (**Hide notification contents**).

### Settings (#80, thanks @viktorstarscollector)

- **Profile photos for accounts.** Open an account's menu and choose **Change photo**. PNG or JPEG, kept on your computer only.
- **About whatRust.** Updates moved to the bottom of the sidebar as **About whatRust**, with the list of everyone who contributed code.
- The arrow inside drop-down boxes is centred.
- Shortcuts read `Cmd/Ctrl+Shift+W` instead of `CmdOrCtrl+Shift+W`.

If you are on 0.6.11 or later, whatRust installs this update on its own (AppImage, macOS, Windows) or offers it in **Settings → About whatRust** (.deb, Flatpak).

### Install or update

```bash
# Linux (Flatpak)
curl -fsSL https://raw.githubusercontent.com/karem505/whatRust/master/install-flatpak.sh | sh
# Linux (AppImage) and macOS
curl -fsSL https://raw.githubusercontent.com/karem505/whatRust/master/install.sh | sh
```

On Windows, run the `x64-setup.exe` or `.msi` below. 0.6.10 and older don't have the updater, so install this version by hand once.

**macOS `.dmg`: "whatRust is damaged and can't be opened"?** The app isn't damaged. It is not signed with an Apple Developer ID, so macOS blocks it after a browser download. Drag it into Applications, run `xattr -dr com.apple.quarantine /Applications/whatRust.app` once in Terminal, and open it again. The `install.sh` line above does this for you.
